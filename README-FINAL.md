# ハクサンリーグ・旧市町村ジムバッジ

**白山市NFCジムバッジラリー - 完全版デジタル観光アプリ**

## 🎯 プロジェクト概要

白山市の8つの旧市町村（鶴来・美川・松任・河内・白峰・吉野谷・鳥越・尾口）を巡る、完全な著作権クリア対応デジタル観光体験アプリです。

## ✨ 主要機能

### 🏅 バッジ収集システム
- **8つの地域バッジ**: 各旧市町村固有のデザインバッジ
- **NFC連携**: NFCタグまたはQRコードでバッジ取得
- **進捗管理**: リアルタイム収集状況表示
- **実績システム**: 収集に応じた実績解除

### 📸 AR写真撮影機能
- **バッジオーバーレイ**: 取得バッジを実世界に合成
- **カスタマイズ**: 位置・サイズ・スタイル調整
- **写真保存**: 高品質画像の保存・共有
- **履歴管理**: 撮影写真の自動記録

### 🎨 ピクセルアバターシステム
- **32x32ドット絵**: 完全カスタマイズ可能
- **リアルタイム編集**: 直感的なピクセル編集ツール
- **プリセット**: 人間・ネコ・ロボットテンプレート
- **エクスポート**: PNG形式での画像出力

### 📊 リアル統計システム
- **利用統計**: セッション時間・クリック数・機能利用頻度
- **地域別データ**: 各地域の訪問統計
- **実績進捗**: 解除済み実績とその履歴
- **データエクスポート**: JSON形式での統計データ出力

### 🗺️ インタラクティブマップ
- **RPGスタイル**: 3D地形表現と天候効果
- **リアルタイム更新**: バッジ取得状況の即座反映
- **ズーム機能**: 詳細表示対応
- **アニメーション**: 滑らかな視覚効果

### 📱 PWA (Progressive Web App)
- **オフライン対応**: Service Worker実装
- **アプリインストール**: ネイティブアプリ風体験
- **レスポンシブ**: 全デバイス対応
- **プッシュ通知**: 重要な更新の通知

## 🎮 使用方法

### 基本的な使い方
1. **アプリアクセス**: ブラウザでindex.htmlを開く
2. **バッジ取得**: 各地域のNFCタグをスキャンまたはQRコード読み取り
3. **進捗確認**: メイン画面で収集状況をチェック
4. **機能活用**: AR写真・アバター作成・統計閲覧を楽しむ

### URL取得システム
```
?badge=地域名
```
- 例: `?badge=tsurugi` で鶴来バッジを取得

### 対応地域
- **鶴来** (tsurugi): クレインバッジ ⛩️
- **美川** (mikawa): ラッパバッジ 🌊  
- **松任** (mattou): パインバッジ 🏛️
- **河内** (kawachi): ブリッジバッジ 🌉
- **白峰** (shiramine): ピークバッジ ⛰️ (レジェンダリー)
- **吉野谷** (yoshinodani): フォレストバッジ 🌸
- **鳥越** (torigoe): キャッスルバッジ 🏰
- **尾口** (oguchi): フォールバッジ 💧

## 🚀 セットアップ・デプロイ

### ローカル開発環境
1. **ファイル配置**: 全ファイルを同一ディレクトリに配置
2. **ローカルサーバー**: HTTPSサーバーで起動（AR機能のため）
3. **ブラウザ**: モダンブラウザでアクセス

### 測定指標
- **LCP**: 2.5秒以下（画像最適化）
- **FID**: 100ms以下（JavaScript最適化）
- **CLS**: 0.1以下（レイアウト安定性）

## 🔐 プライバシー・セキュリティ

### データ保護
- **ローカル保存**: 個人データはデバイス内保存
- **サーバーレス**: 外部サーバーへの送信なし
- **匿名**: 個人特定情報の収集なし

### セキュリティ対策
- **CSP**: Content Security Policy設定
- **HTTPS**: 暗号化通信必須
- **入力検証**: XSS/インジェクション対策
